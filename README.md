# Thiệp cưới

Trang giới thiệu (landing page) **tĩnh** — thiệp mời cưới trực tuyến. Tên cô dâu chú rể, ngày cưới và địa điểm đang chờ bổ sung. Trang được dựng bằng HTML, CSS và JavaScript thuần, không cần bước biên dịch.

> Mọi tên, số điện thoại, địa chỉ và số liệu trên trang đều là **dữ liệu mẫu**. Giá hiển thị là **giá mẫu**. Biểu mẫu (nếu có) chỉ là giao diện minh họa: không gửi dữ liệu đi đâu và không có backend.

**Demo trực tuyến:** https://m-software-thiep-cuoi-truc-tuyen.genalpha.dev
**Giấy phép:** [MIT](LICENSE) © M-Software

## Cách xem

Mở `index.html` bằng trình duyệt (nhấp đúp, không cần máy chủ), hoặc mở liên kết demo ở trên. Giữ nguyên các tệp cùng thư mục vì liên kết là tương đối.

| Tệp | Nội dung |
|---|---|
| `LICENSE` | Giấy phép MIT |
| `README.md` | Tài liệu giới thiệu này |
| `index.html` | Trang chính |
| `main.js` | JavaScript của trang |
| `rsvp.html` | Trang nội dung |
| `styles.css` | Bảng định kiểu (toàn bộ giao diện) |

## English

A **static** landing page for Thiệp cưới, built with plain HTML, CSS and JavaScript. All names, contact details and figures shown are sample data, displayed prices are sample prices, and any form is interface-only — nothing is submitted and there is no backend. Open `index.html` in a browser. Licensed under MIT.
